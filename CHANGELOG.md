# Changelog

## 0.1.0 — experimental, unreleased

- Native GTK4/libadwaita interface with light/dark styling.
- Hugging Face discovery, application filters, model details and pagination.
- Ollama downloads, configuration, tool-call check and uninstall flow.
- Conservative hardware-aware variant suggestions with visible limitations.
- Optional OpenCode providers-format integration and metadata/configuration backups.
- Per-user installation, portable paths and reproducible demo screenshots.

Release preparation is tested on CachyOS/GNOME. No Windows/macOS support is claimed.
